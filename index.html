Política de Privacidad

Última actualización: 25 de noviembre de 2026

1. Información que recopilamos

Recopilamos un ID de Firebase de la cuenta del usuario, su nombre, su correo y dirección/comuna.

Además de registros de fallos, diagnósticos y estadísticas de rendimiento de la aplicación.

2. Servicios de terceros

  • Firebase Authentication: Para la gestión de inicio de sesión de usuarios de forma segura.
  • Cloud Firestore: Base de datos NoSQL cifrada en la nube para almacenar datos de los perfiles de los usuarios, puntos de reciclaje y publicaciones en el foro.
  • Firebase Analytics y Crashlytics: Para identificar errores técnicos y mejorar la estabilidad de la aplicación.
  • Firebase Cloud Messaging (FCM): Para el envío de notificaciones de nuevos puntos de reciclaje añadidos.
  • OSDMaps: Que permite mostrar un mapa geográfico dentro de la aplicación.
  • Overpass API: Para realizar consultas web de los puntos de reciclajes cercanos, y añadirlos como marcadores dentro del mapa.

3. Permisos solicitados por Android

  • INTERNET: Necesario para comunicar con la base de datos de Firebase y servicios en la nube.
  • POST_NOTIFICATIONS: Necesario para poder enseñar notificaciones de nuevos puntos de reciclaje añadidos.
  • ACCESS_COARSE_LOCATION: Opcional para acceder a la ubicación aproximada del dispositivo.
  • ACCESS_FINE_LOCATION: Opcional para acceder a la ubicación exacta del dispositivo.

4. Almacenamiento y seguridad de los datos

Toda la información transmitida entre la aplicación móvil y los servidores de Firebase/Google Cloud se realiza mediante conexiones seguras cifradas con protocolos HTTPS / TLS 1.3. Los datos almacenados en Cloud Firestore están protegidos mediante reglas de seguridad de acceso restringido.

5. Derechos de usuario y eliminación de datos

Conforme a las normativas de protección de datos personales y las políticas de Google Play Store, tienes derecho a:

  • Acceder, modificar o rectificar tus datos personales y los de tus mascotas.
  • Solicitar la eliminación completa de tu cuenta de usuario y de todos los registros asociados en nuestra base de datos.

Para solicitar la eliminación de tu cuenta o datos personales, puedes contactarnos enviando tu contacto al siguiente formulario: Formulario de solicitud de eliminación de datos .
